athc - COMMANDS
===============

What each athc tool does, with examples. For installation and setup,
see README.txt in this same folder.

Run tools from any terminal (Command Prompt or PowerShell):

   athc --help                        list top-level commands
   athc <group> --help                list subcommands in a group
   athc <group> <subcommand> --help   show help for one subcommand

USAGE_ORIGINAL.txt in this same folder keeps each command's help as it was
before 1.0, for reference; run --help for the current help.

Settings live in athc.toml (the file documents every option inline). Each league
is a folder under leagues\ next to it: league.toml (path, play_path, team,
ppp_path, category names, and any convert-pdb settings that differ from
athc.toml's) and rule files (gameplan.toml, profile.toml, scheduler.toml).
League-aware tools use the league named by [athc] league unless the command is
given --league NAME.

Game plan and profile keys: off1, def1, off2 and def2 name your team's
1st-half offense, 1st-half defense, 2nd-half offense and 2nd-half defense
file, found in ppp_path in league.toml, else where the league file puts them.
team in league.toml is your team; --team NAME picks another team for one run.
A file or folder that exists by that name wins over the key.


1) gameplan check  --  check game plans against the league's rules
   ---------------------------------------------------------------

   Rules come from the league's gameplan.toml. The play pool comes from
   the league's play_path. Each play's side, category and attributes (QB run,
   rollout, timed pass, defensive front) come from the play file, so any folder
   layout works; the PNFL layout (Offense/Defense/Special with category
   subfolders) is optional and only adds screen passes and misfiled-play
   warnings. With no gameplan rules configured, check reports an error and
   stops. With no path, every .pln in the current folder is checked (the
   whole tree with -r). A game plan key checks one of your team's game
   plans. To check your team's game plans with their profiles, run
   athc check-ppp.

   Show help:
      athc gameplan check --help

   Example terminal calls:
      athc gameplan check
      athc gameplan check off1
      athc gameplan check plans -r
      athc gameplan check offense.pln --league PCFL


2) gameplan list-normals  --  list the 64 normal plays in a game plan
   ------------------------------------------------------------------

   Default writes <name>.normals.txt next to the .pln, replacing any existing
   copy; pass an output file or folder to write elsewhere (a name with no
   extension gets .txt), or - to print to the screen.
   The game plan is a .pln file or a game plan key. A file's first line is a
   `::` comment with the absolute path of the source .pln. --sort name lists
   alphabetically (default keeps slot order). --sort category groups the
   plays by category, each group under a `::` comment with the league's
   category name from league.toml (RL, RM, ... for offense; RunLeft,
   RunMiddle, ... for defense; the game's name where the league has none); a
   category with no plays gets no header.

   Show help:
      athc gameplan list-normals -h

   Example terminal calls:
      athc gameplan list-normals off1
      athc gameplan list-normals DEN-OGP1.pln plays.txt --sort category
      athc gameplan list-normals off1 lists\
      athc gameplan list-normals offense.pln -


3) gameplan list-specials  --  list the special-teams plays in a game plan
   -----------------------------------------------------------------------

   Lists them in game plan order. Default writes <name>.specials.txt next to
   the .pln, replacing any existing copy; pass an output file or folder to
   write elsewhere (a name with no extension gets .txt), or - to print to
   the screen. The game plan is a .pln file or a game plan key. A file's
   first line is a `::` comment with the absolute source path.

   Show help:
      athc gameplan list-specials -h

   Example terminal calls:
      athc gameplan list-specials def1 -
      athc gameplan list-specials DEN-DGP1.pln spec.txt


4) gameplan find-play  --  find plays by name in game plans
   --------------------------------------------------------

   Searches your team's game plans, or the ones --path names: a .pln file,
   a folder, a wildcard or a game plan key (-r includes subfolders). Every
   argument is a play. Case-insensitive; only the normal and special-teams
   slots are searched (stock/clock slots skipped). Hits show the slot(s),
   e.g. 'OR45RL01' found in slots 1-3, 16-2; special-teams hits add the
   category, e.g. 'BCFGPAT' found in special slot 1 (Field Goal/PAT). No pool
   setup needed -- the category is read from the .pln. A single game plan
   without the play prints `not found`; a folder, a wildcard or your team's
   game plans list only their hits and end with a per-play summary.

   Show help:
      athc gameplan find-play -h

   Example terminal calls:
      athc gameplan find-play OR45RL01
      athc gameplan find-play OR45RL01 BCFGPAT --path plans -r
      athc gameplan find-play OR45RL01 --path .


5) gameplan set-normals  --  set the 64 normal plays from a play list
   ------------------------------------------------------------------

   Replaces the normal slots of one game plan (a .pln file or a game plan
   key) from a play list file; - reads the list from the screen instead. No
   backup is made. Lines starting with `::`, and text after ` ::`, are
   ignored. The league's play pool resolves names; run `check` afterward.
   To hide the OK lines, redirect them:  > nul  (FAIL lines still show).

   Show help:
      athc gameplan set-normals -h

   Example terminal calls:
      athc gameplan set-normals off1 plays.txt
      athc gameplan set-normals DEN-OGP1.pln -
      athc gameplan set-normals offense.pln plays.txt > nul


6) gameplan set-specials  --  set the special-teams plays from a play list
   -----------------------------------------------------------------------

   Updates your team's game plans, or the ones --path names: a .pln file, a
   folder, a wildcard or a game plan key (-r includes subfolders), from a
   play list file; - reads the list from the screen instead. Game plans of
   the other side are skipped with a SKIP line. Categories not in the list
   keep their plays. No backup is made. Comment syntax: same as set-normals.

   Show help:
      athc gameplan set-specials -h

   Example terminal calls:
      athc gameplan set-specials spec.txt
      athc gameplan set-specials spec.txt --path plans -r


7) gameplan replace-play  --  replace one play with another in game plans
   ----------------------------------------------------------------------

   Replaces every instance of one play in your team's game plans, or the
   ones --path names: a .pln file, a folder, a wildcard or a game plan key
   (-r includes subfolders). Searches the normal and special-teams slots,
   case-insensitive (same as find-play); only matching slots change, the
   rest are left alone.

   List one or more replacement plays: each game plan gets the first one that
   is not already in it and with which it passes `gameplan check`; the
   others are backups, tried in order. Every replacement
   must exist in the league's play pool (its play_path); the play being
   replaced need not (it may already be gone). No backup file is made.

   Each replaced play prints a line; a play in several slots lists them all
   in brackets at the end, e.g.:
      offense.pln: 'OR45RL01' (RL) replaced with 'OR43RM02' (RM) [1-3][4-2]
   A replacement passed over prints a SKIP line saying why; a game plan no
   replacement fits prints "not replaced, no valid replacement" and is left
   unchanged.

   Show help:
      athc gameplan replace-play -h

   Example terminal calls:
      athc gameplan replace-play OLDRUN NEWRUN
      athc gameplan replace-play OLDRUN NEWRUN BACKUP --path plans -r
      athc gameplan replace-play OLDRUN NEWRUN --path off1


8) profile check  --  check profiles against the league's rules
   ------------------------------------------------------------

   Rules come from the league's profile.toml. With no rules configured,
   check reports an error and stops. With no path, every .prf in the current
   folder is checked (the whole tree with -r). A profile key checks one of
   your team's profiles. To check a profile together with its game plan, run
   athc check-ppp.

   Show help:
      athc profile check -h

   Example terminal calls:
      athc profile check
      athc profile check off2
      athc profile check drafts\*OFF*.prf
      athc profile check profiles -r --league PCFL


9) profile copy  --  copy settings from one profile to others
   ----------------------------------------------------------

   Copies the settings you pick (--stop-clock, --substitutions,
   --field-goal-range, --fourth-down, --goal-line, --pat-logic) from SOURCE
   into each TARGET. SOURCE is a .prf file or a profile key; each TARGET is
   a .prf file, a folder (-r includes subfolders), a wildcard or a profile
   key. Targets of the other side, and the source itself, are skipped with a
   SKIP line; the source as the only TARGET file is an error. No backup is
   made. Copy does not check the rules -- run
   athc profile check afterward.

   Show help:
      athc profile copy -h

   Example terminal calls:
      athc profile copy off1 off2 --stop-clock --substitutions
      athc profile copy new.prf off1 off2 --substitutions
      athc profile copy SRC.prf profiles --stop-clock -r


10) profile diff  --  show differences between two profiles
    -------------------------------------------------------

   Compares situations, PAT situations, substitutions, field-goal range,
   and audibles; only changed records are shown. Both profiles must be the
   same side; each is a .prf file or a profile key. Prints to the screen, or
   with --output FILE writes a report (.txt report, .csv one row per changed
   record for Excel).

   Show help:
      athc profile diff -h

   Example terminal calls:
      athc profile diff off1 off2
      athc profile diff off1 try.prf -o changes.csv


11) check-ppp  --  check profiles against their game plans
    -------------------------------------------------------

   Checks your team's .prf coaching profiles with their .pln game plans, as
   the league's FbPro98 files pair them: 1st-half offense profile with
   1st-half offense game plan, and so on. The .lg2 and .lge files are read
   from the folder that path in league.toml names; team in league.toml is
   your team (its name or nickname), --team NAME picks another team for one
   run, and --all-teams checks every team.

   With no path, the files are where the league file puts them, or in
   ppp_path in league.toml for your team. Give a folder (. is the current
   one) to check the files there instead, found by their league file names
   (a whole tree with -r, each folder on its own). One .prf and one .pln, in
   either order, are checked as a pair.

   Each file gets the same check as profile check and gameplan check, with
   the rules from the current league; --league picks another league. A pair
   must be the same side. The league's profile.toml decides whether profile
   categories with no custom play in the game plan fail the check, and its
   gameplan.toml whether game plan categories the profile never uses do.
   Unused game plan categories that don't fail are listed as info only. A
   game plan used for both halves is reported once.

   Missing files: where the league file puts them, a missing file is a FAIL
   and its partner is checked alone. In a folder nothing has to be there:
   a missing partner is a WARN, counted as missing in the tally (a whole
   pair absent prints nothing and counts nowhere), and a team with no file
   is one WARN.

   Show help:
      athc check-ppp -h

   Example terminal calls:
      athc check-ppp
      athc check-ppp .
      athc check-ppp --all-teams handed-in -r
      athc check-ppp --team "Las Vegas" handed-in
      athc check-ppp DEN-OFF1.prf DEN-OGP1.pln


12) playpool check  --  check the play pool for misfiled and duplicate plays
    ------------------------------------------------------------------------

   With no folder, checks every play under the league's play_path; when
   play_path is not set, missing or not a folder, the line says to run
   athc config set play_path FOLDER or pass the folder. Give a folder (. is
   the current one) to check it instead; then play_path is not read, and no
   league is needed, though a configured league still names the category
   folders. --league picks another league. Reports plays in a folder that
   doesn't match the play file, duplicate play names, and invalid play files
   -- the same warnings other commands show when they load the play pool.
   Ends with a count of plays checked and issues found.

   Show help:
      athc playpool check -h

   Example terminal calls:
      athc playpool check
      athc playpool check .
      athc playpool check newplays
      athc playpool check --league PCFL


13) convert-pdb  --  convert a WinLogStats PDB to an Excel workbook
    ---------------------------------------------------------------

   Builds an Excel workbook from a WinLogStats .pdb: Run Plays, Pass Plays
   and Def Plays sheets (one row per team and play, plus a Total Stats team
   summing every team), a Tendencies sheet (run/pass counts by down and
   distance) and an Options sheet. With no output file it writes
   <name>.xlsm beside the PDB, replacing any existing copy; name an .xlsx or
   .xlsm output file, or a folder, to write elsewhere (a name with no
   extension gets .xlsm). An .xlsm has the built-in sorting:
   double-click a column to sort by it (stat columns toggle between
   descending and ascending; Team, Category, Slot, Play and Type sort
   ascending only). Excel opens an .xlsm with its macros disabled until you
   click Enable Content, and a copy sent by email opens with them blocked
   (unblock it in the file's Properties, or make an .xlsx to share).

   Slot 1 and Slot 2 show where each play sits in your team's 1st- and
   2nd-half game plans, per side. With no game plan option, they come from
   the league file: --path FOLDER, else ppp_path in league.toml for your
   team, else where the league file puts them; team in league.toml is your
   team and --team NAME picks another. A missing plan is a WARN and hides its
   column. With -o, -o2, -d or -d2, only the game plans given are used, each
   must be the right side, and the league file is not read. Without a team
   and with no game plan option, the Slot columns are hidden.

   league.toml names the league's categories (RL, PSL, RunLeft, ...). The
   settings live in athc.toml under [convert-pdb]: the workbook options
   (percentage columns, sacks excluded from pass attempts), the order the
   categories sort in ([convert-pdb.category_order]) and the deleted plays to
   skip. A league that differs puts the same tables in its league.toml with
   only the keys that differ. The Type column's QB run and defensive front
   come from each play file. --percentages / --no-percentages override the
   percentage columns for one run.

   Show help:
      athc convert-pdb --help

   Example terminal calls:
      athc convert-pdb 49W6.pdb
      athc convert-pdb 49W6.pdb reports\week6.xlsx
      athc convert-pdb 49W6.pdb reports\
      athc convert-pdb 49W6.pdb --team Broncos
      athc convert-pdb 49W6.pdb -o try3.pln -o2 plans\DEN-OGP1.pln
      athc convert-pdb 49W5.pdb --path plans\wk5
      athc convert-pdb 2045-2047.pdb --no-percentages --league PCFL
      for %f in (*.pdb) do athc convert-pdb "%f"


14) autocontinue  --  auto-click the FbPro '98 'Continue' button between plays
    --------------------------------------------------------------------------

   Watches for the 'Continue' button and clicks it between plays. At halftime
   it moves the mouse to Return, waits halftime_pause seconds (8 by default)
   and clicks; at the end of the game it moves the mouse to Return and stops.
   With drive_league_pregame on (as shipped), it clicks through the league
   play pre-game screen (Plans/Profiles, Visitor, Conditions, Venues) and
   clicks Game; a pause of 0 skips its click. Settings live in athc.toml
   ([autocontinue] mouse_move_duration, continue_pause, halftime_pause,
   hot_corner, drive_league_pregame, plans_profiles_pause, conditions_pause,
   venues_pause); every one is optional (a missing one uses the shipped value,
   except drive_league_pregame, which is off when missing), and the file is
   re-read whenever it changes. It only clicks while the game is the active
   window, so switching to another app is safe, and it checks a button is
   still there just before clicking it, so clicking one yourself is safe too. Run the game on your
   primary monitor (autocontinue only watches that display; a single-display
   VM works too). Stop it with Ctrl+C, or by moving the mouse to the top-left
   screen corner (the "hot corner", on by default). Run one copy at a time;
   two copies both click.

   --continue-pause SECONDS sets the wait before each Continue click for one
   run; it does not change halftime_pause. -n, --dry-run reports what it finds
   each time and never moves the mouse or clicks: a way to check a new monitor
   or display scaling.

   Set hot_corner = false (or pass --no-hot-corner) to turn the corner off and
   use Ctrl+C only; --hot-corner forces it on for one run.

   Show help:
      athc autocontinue --help

   Example terminal calls:
      athc autocontinue
      athc autocontinue --continue-pause 3
      athc autocontinue --dry-run
      athc autocontinue --no-hot-corner


15) config  --  show or change athc settings (athc.toml, league.toml)
    ---------------------------------------------------------------

   Helpers for the settings files: athc.toml, and a league's league.toml.
   `path`, `edit` and `reveal` take FILE, athc.toml (the default) or
   league.toml, and --league NAME (which makes league.toml the default).
   `path` prints the file's full path; `edit` opens it in its default app
   (a missing athc.toml is created empty; a missing league.toml is a FAIL);
   `reveal` shows the file in File Explorer (selected), or its folder if it
   doesn't exist yet.

   `get KEY` prints a setting: league from athc.toml; path, play_path, team
   and ppp_path from the league's league.toml (--league NAME picks another
   league). `set KEY VALUE` writes one: league to athc.toml (the value must be
   a folder under leagues\), the other four to the league's league.toml. It
   keeps your comments in both files and prints an OK line naming the file
   it wrote, e.g. OK   <league.toml>: team = Denver.

   Show help:
      athc config --help

   Example terminal calls:
      athc config path
      athc config edit league.toml
      athc config reveal
      athc config get play_path
      athc config set league PNFL
      athc config set play_path C:\SIERRA\FBPRO98\PNFL
      athc config set team Denver


16) standings  --  show the league's standings as played so far
    -----------------------------------------------------------

   Reads the league's .lge from the folder path names in its league.toml.
   --view game (the default) shows the game's standings screen; --view
   league, conference or division shows ESPN's tab of that name, with home,
   away, division and conference records, point difference and streak.
   --method picks the tie-breakers: scheduler (the default), game or nfl.

   Show help:
      athc standings -h

   Example terminal calls:
      athc standings
      athc standings --view league
      athc standings --view division --method nfl --league PCFL


EXIT CODES
==========

   The same numbers in every command, so a script can treat 2 as "athc
   could not do it" everywhere:
      0    done -- clean, or with warnings only
      1    findings -- ran fine and reported problems in valid input
           (violations, play pool issues, differences, a play found
           nowhere, nothing replaced, no valid replacement); only gameplan
           check, find-play, replace-play, profile check, profile diff,
           check-ppp and playpool check use it
      2    error -- could not do the job: bad arguments, a config, league
           or rules problem, a missing or bad file, a file that failed
           inside a batch, a missing dependency, or a bug
      130  stopped with Ctrl-C (autocontinue stops that way on purpose, so
           there it is 0)

   A batch (a folder or a list of files) processes every file, then exits
   with the worst outcome: error beats findings beats clean. Warnings never
   change the code.

   A status line starts with a label: OK (done), SKIP (left alone on
   purpose), WARN (noted, nothing failed), FAIL (that item, or the run,
   failed). Results, OK and SKIP go to standard output; progress, WARN and
   FAIL to standard error, so  > out.txt  keeps the results and  2> err.txt
   the problems. Every status line is also in the run log,
   %LOCALAPPDATA%\athc\Logs\athc.log.

# convert-pdb CLI plan

**Goal:** `athc convert-pdb 49W6.pdb` with nothing else turns a WinLogStats stats file into `49W6.xlsm` beside it, with the Slot columns filled from your team's four game plans where the league file puts them (or in `ppp_path`); each game plan option replaces one slot with a file or one of the four names, `--path` points at a folder of them (an archived week), `--team` picks the team for one run, and an output path overrides the derived name; a coach with no team set gets the workbook as today, without Slot columns.

**Status:** proposal, 2026-10-13; nothing changed yet. Every choice is decided below, with its reason next to it. Reviewed in three rounds (coach workflows, codebase fit, consistency with the gameplan and profile plans and cli-help.md rules 16 to 28); the findings are folded in. Depends on cli-help.md landing first. Describes main at ddae7a1 (play tags from the play files, `playpool.toml` gone) and dade898 (generate-schedule from the league's `.lge` files), 2026-10-13.

## 1. Today

- `athc convert-pdb pdb_file output_file` (`src/athc/cli/convert_pdb.py`): both required, the placeholders lowercase (`metavar="pdb_file"`, `"output_file"`, `"pln_file"`, `--league name`; the arguments are named `pdbfile` and `outputfile`). `pdb_file` must end in `.pdb`, `output_file` in `.xlsx` or `.xlsm`, each checked by a Click callback (`Error: Invalid value for 'pdb_file': must have a .pdb extension.`, exit 2). The PDB and every game plan given go through `named_file` before anything is read: a missing one is `FAIL <path>: The system cannot find the file specified.`, a folder `Access is denied.`, exit 2.
- `-o/--pln-off`, `-o2/--pln-off-2`, `-d/--pln-def`, `-d2/--pln-def-2`, one `.pln` each (`pln_file`), fill the Slot 1 and Slot 2 columns of the Run, Pass and Def Plays sheets with each play's position in that plan (`row-column`, `3-2`; `workbook_creator.py` `_get_play_slots`). A Slot column is hidden when the count of plans for that side is below its number (`excel_workbook.py` `_slot_options`), so a run with only `-o2` hides the column it fills. The side is not checked: a defense plan under `-o` matches nothing and leaves the column blank. Nothing says which plan filled which column; the Options sheet lists only the highlight option, the category order and the sorting notes.
- `--skip-calcs` drops the percentage columns for one run; `calculate_percentages` in `[convert-pdb]` in `athc.ini` drops them for every run; they show only when both say so (`show_percentages = perform_calculations and config.calculate_percentages`). Nothing turns them on for one run when the setting is off.
- `--league name`. Settings read: `play_path` and the category labels from `league.toml`; `pdbtoexcel.toml`, required (`[category_order]`, `[deleted_plays]`); `[convert-pdb]` in `athc.ini` (`calculate_percentages`, `include_category_worksheets`, `exclude_sacks_from_pass_attempts`). The tool's `Config` (`src/athc/pdbtoexcel/config.py`) holds those and not the `LeagueConfig`; it is loaded inside the tool (`src/athc/pdbtoexcel/main.py` `convert_pdb()` calls `load_config` and `play_dir`); a missing `play_path` or `pdbtoexcel.toml` is a `FAIL` naming the file, exit 2.
- Lines: `Creating '<output>'` as progress on stderr; a `WARN` per notice (a play with no play file, a stale deleted play, bad PDB data, a pool issue; the play tags come from the play files since ddae7a1, so there is no rules file and no rules notice); `OK   <output>: <n> play(s)`. Codes: 0 done, warnings included; 2 error or usage; never 1 (architecture.md names the code-1 commands, and this is not one). The output's missing folders are created in full; an existing workbook is replaced; one still open in Excel is `FAIL <output>: The process cannot access the file because it is being used by another process.` (`excel_workbook.py` `__exit__`).
- Usage errors are Click's: `UsageError.show()` (`click/exceptions.py`) prints the usage line, `Try 'athc convert-pdb --help' for help.` and `Error: <message>`; athc's `_OnePlace.main` (`src/athc/cli/__init__.py`) catches the `ClickException`, calls `error.show()` and logs `error.format_message()`. Click's own `Got unexpected extra argument (x)` has no period.
- A bare `athc convert-pdb` is Click's `Missing argument` usage error. Two PDBs on the line bind the second to `output_file` and fail its extension check. Nothing knows which team is yours; the four `.pln` paths are typed every week, though the league's `.lg2` names them.
- The real league today (`E:\SIERRA\FbPro98\PNFL.lg2` and `PNFL.lge`, the 2048 season, read 2026-10-13): 18 teams, one folder each (`PNFL\2048\Plans\<Team (Coach)>`); Denver (team 5) uses `DEN-OGP1.pln`, `DEN-OGP2.pln`, `DEN-DGP1.pln`, `DEN-DGP2.pln`; four teams (Las Vegas, Los Angeles, Pittsburgh, Minnesota) use one offense plan and one defense plan for both halves (`RAIDEROFF.pln`, `PS-O.pln`, `MN-D.pln`). The test fixture `tests/integration/data/PNFL.lg2` is the 2049 file: three sharing teams (Las Vegas, Pittsburgh, Minnesota) and no Los Angeles. The game's `GameLogs` folder holds the `.pdb` files WinLogStats made, one per week, named by season and week (`47W1AB.pdb`, `45W17_Test.pdb`); the test fixture is `2045-2047.pdb`. No `.pdb` sits in the game folder itself or in the plays folder.

## 3. What other tools do

- **The input is named; the output is derived from it.** pdftotext: "pdftotext [options] [PDF-file [text-file]]"; "If text-file is not specified, pdftotext converts file.pdf to file.txt." uv build: `uv build [OPTIONS] [SRC]`, SRC "Defaults to the current working directory", and `-o/--out-dir` "Defaults to the `dist` subdirectory within the source directory". LibreOffice `--convert-to pdf *.doc`: "In absence of --outdir, current working directory is used for the result." athc's own `list-normals` writes `<name>.normals.txt` beside the game plan when no output file is given (architecture.md, Output files: "by default it lands next to its source").
- **Converters that take both names take the input first and the output last.** ffmpeg: "Anything found on the command line which cannot be interpreted as an option is considered to be an output url." ImageMagick: "one or more required input filenames", then "zero or one output image filenames", as in `magick image.jpg image.png`; "ImageMagick leverages the filename extension to determine the format." Windows `ren <filename1> <filename2>`: both named. Windows `copy`: "If you don't specify a destination file, a copy is created with the same name" in "the current directory on the current drive".
- **One input per run, or many.** For one: pdftotext's synopsis above; Windows `copy`: "If you specify more than one file in source, the copy command combines them all into a single file using the file name specified in destination." For many: LibreOffice's `--convert-to pdf *.doc`; clig.dev: "Multiple arguments are fine for simple actions against multiple files." and "This also makes it work with globbing: `rm *.txt`." Windows' own loop: `for {%% | %}<variable> in (<set>) do <command> [<commandlineoptions>]`, "Use a single percent sign (%) to carry out the for command at the command prompt. Use double percent signs (%%) to carry out the for command within a batch file."; "You can use wildcard characters (* and ?) to specify a file set."; the example `for %f in (*.doc *.txt) do type %f`.
- **Binary output never goes to the console.** pandoc: "odt, docx, epub, and pdf output will not be directed to stdout unless forced with -o -".
- **An existing output is replaced, or the tool asks.** ffmpeg `-y`: "Overwrite output files without asking."; `-n`: "Do not overwrite output files, and exit immediately if a specified output file already exists." Windows `copy /y`: "Suppresses prompting to confirm that you want to overwrite an existing destination file." athc's rule is replace (architecture.md: "An existing file at the path is replaced.").
- **Macro-enabled workbooks.** Microsoft: Office blocks "macros in files from the internet"; "Mark of the Web is added by Windows to files from an untrusted location, such as the internet or Restricted Zone. For example, browser downloads or email attachments."; a file without it opens under the Trust Center default, "Disable all macros with notification (default)", with the Enable Content bar.
- **A configured default, named only when it is used.** pytest's `testpaths`: "Directories to search for tests when no files or directories are given on the command line"; its header prints `testpaths: tests` only when the run used them (`_pytest/terminal.py`: `if config.args_source == Config.ArgsSource.TESTPATHS`). kubectl's saved namespace and `-n` for one request (check-ppp plan, section 3).
- **Flags beat config, one parameter at a time; an on/off pair overrides a boolean setting both ways.** clig.dev: "Apply configuration parameters in order of precedence", flags first. git: "When there is a configuration variable or an environment variable that tweak the behaviour of an aspect of a Git command, and also a command line option that tweaks the same, the command line option overrides what the configuration and/or environment variable say." and "Options with long option names can be negated by prefixing --no-." kubectl's `-n` overrides the context's namespace and leaves its cluster and user alone (check-ppp plan, decision 4). Click: "declare `--{on-option}/--{off-option}`" and "Click will automatically set `is_flag=True`"; athc's `autocontinue --hot-corner/--no-hot-corner` with `default=None` leaves the setting alone when neither is passed (`src/athc/cli/autocontinue.py`); Click's help shows the pair as `--hot-corner / --no-hot-corner` (`core.py` `get_help_record`, `" / ".join`).
- **Standard flags and defaults.** clig.dev: "Use standard names for flags, if there is a standard", listing "`-o`, `--output`: Output file."; "Be consistent across subcommands"; "Make the default the right thing for most users."; "Display output on success, but keep it brief."; "Suggest commands the user should run."
- **Multi-character single-dash options.** Click's docs say "Multi-character short option names are not supported", but its parser files `-o2` as a long option (`parser.py` `_Option.__init__`: a one-character prefix with a one-character value is short, "else: self._long_opts.append(opt)") and tries the long match first (`_process_opts`: "this allows options like "-foo" to be matched as long options"), which is why `-o2` works today and keeps working.
- **A named file that is missing is an error; a discovered one is not.** check-ppp plan, section 3 and decision 6: a pair's partner missing from a folder is a `WARN`; athc's `collect_files` makes a folder with nothing matching a `WARN`.
- **An existing name is a path.** cli-help.md rule 15: "A name that exists is a name, never a wildcard"; `replace-play`'s `_is_path` takes an existing file or folder first (`src/athc/cli/gameplan/replace_play.py`).

## 4. Decisions

1. **`PDB_FILE` stays required and positional, one per run; `OUTPUT_FILE` becomes optional.** Every converter checked names its input (ffmpeg, ImageMagick, pdftotext, LibreOffice, Windows `ren`), and nothing configured can stand in for it: the `.pdb` files are named by season and week and live where the coach put them. The output is derivable, and pdftotext, uv build, LibreOffice and athc's `list-normals` derive it. A bare `athc convert-pdb` is Click's `Missing argument 'PDB_FILE'.` usage error, exit 2.
2. **One PDB per run; several go through Windows' `for` loop.** WinLogStats makes one PDB a week (the `GameLogs` names), so a batch is a one-time catch-up, not the weekly run; with one input the output stays an unambiguous positional, where Windows `copy` with several sources "combines them all into a single file"; and the loop is one line, `for %f in (*.pdb) do athc convert-pdb "%f"`, which the derived output name makes possible. A second `.pdb` where `OUTPUT_FILE` goes, and a wildcard in `PDB_FILE` (a literal one once cli-help.md turns Click's expansion off; `PDB_FILE` is not one of rule 15's wildcard arguments), are usage errors whose hint sentence is that loop, in check-ppp's hint shape: `To convert several, run for %f in (*.pdb) do athc convert-pdb "%f".` (clig.dev: suggest the command). A name that exists is a name, never a wildcard (rule 15). COMMANDS.txt shows the loop.
3. **The default output is the PDB's name with `.xlsm`, beside the PDB.** Beside it, not in the current folder: `list-normals` puts the product next to its source, and the pair stays together when the PDB sits in the game's `GameLogs` folder. `.xlsm`, not `.xlsx`: the sorting macros are the workbook's point (COMMANDS.txt: "Save as .xlsm for the built-in sorting"; every shipped example writes `.xlsm`); a coach who wants plain `.xlsx`, or another place, names `OUTPUT_FILE`. The cost: Excel opens the workbook with the macros disabled until the coach clicks Enable Content, and a copy sent to another coach by email carries Mark of the Web and opens with its macros blocked; the README and COMMANDS.txt say so in one sentence (unblock it in the file's Properties, or convert to `.xlsx` for sharing). An existing file is replaced (architecture.md). `-` is not an output: the extension check refuses it, as pandoc withholds binary output from the console unless forced; this is an exception to cli-help.md rule 3's "`-` means the console", noted there (section 11).
4. **`OUTPUT_FILE` is a file, never a folder.** pandoc, ffmpeg and ImageMagick take a file; the derived name covers the common case; a folder gets today's `must have a .xlsx or .xlsm extension.` error.
5. **With no game plan option, your team's four game plans fill the Slot columns:** Slot 1 from the 1st-half plan, Slot 2 from the 2nd-half plan, per side (the `.lg2` entry order is 1st-half offense, 1st-half defense, 2nd-half offense, 2nd-half defense; cli-help.md rule 17's four names `off1`, `def1`, `off2`, `def2`). The two Slot columns per side match the two halves exactly, and the Slot columns were the only part of the command that still needed four typed paths every week (row 1). Without a team (`team` unset, no `--team`) and with no name or `--path` asked for, nothing changes from today: the Slot columns are hidden and no line says so, since an optional setting left unset is not a problem (pytest prints nothing about `testpaths` when it is unset). The Slot columns say where each play sits in your plans, whoever ran it, so a league-wide PDB, or one from a game your team did not play, still reads sensibly (a play another team ran that is in your plan shows its slot); no coach workflow needs the default switched off for one run, so there is no off switch.
6. **Each game plan option replaces its own slot; the others keep the team default.** The four options are four named parameters, and a flag overrides the one setting it names (clig.dev's precedence is per parameter; git: "the command line option overrides what the configuration and/or environment variable say"; kubectl's `-n` overrides the namespace and leaves the rest of the context). A coach testing one draft (row 4) keeps the other three columns without typing their paths. Decision 12's lines name every slot athc resolved, so a mixed run says which column came from where. Two typed `.pln` paths to one file, or a typed path and a resolved slot that land on one file, are used as given: two columns, since the coach asked for two; two resolved slots that land on one file collapse as decision 10 says.
7. **A game plan option takes a `.pln` file or one of the four names,** matched without case (cli-help.md rule 17: the four names are accepted wherever a game plan operand is). `-o2 off1` puts the current 1st-half plan beside a draft (row 5). An existing path wins over a name (cli-help.md rules 15 and 17; `replace-play`'s `_is_path`): a folder named `off1` in the current folder is the folder, and the line is `FAIL off1: Access is denied. Run from another folder to use your team's game plan.` (cli-help.md rule 21's sentence with this command's kind); a file named `off1` is read as a game plan.
8. **Four sources for a slot not given as a file, in a fixed order:** `--path FOLDER` on the command line; else `ppp_path` in `league.toml`; else the league locations, `path` joined with the plan's `.lg2` folder (check-ppp plan, decision 3: a path on the command line, else the configured folder, else the league locations). In a folder each plan is found by its `.lg2` file name without case, as check-ppp's folder mode does (its decision 6). `--path` means "where the game plans are" on every command that has it, and what is taken from there follows the command (cli-help.md rule 20): gameplan's batch commands act on every game plan they find there, because they edit or search whatever is there; convert-pdb takes a folder only and picks the team's four plans by their `.lg2` names, because the workbook has exactly four slots. It is an option, not a positional, because the positional is the PDB. `ppp_path` applies only when the team is the one `team` in `league.toml` resolves to (check-ppp plan, decision 4; cli-help.md rule 18): `--team` naming that team goes through it; `--team` naming another team, or `--team` with `team` unset or unresolvable, uses the league locations.
9. **The team is `team` in `league.toml`, `--team NAME` for one run:** the `.lge`'s team name, nickname or both, matched without case, exactly one match (check-ppp plan, decision 5). `--team` or `--path` with nothing left for the league file to name (all four slots given as `.pln` paths) is a contradiction, so a usage error (check-ppp plan, decision 10; cli-help.md rule 18): `Error: Cannot use --team with a path.` and `Error: Cannot use --path when -o, -o2, -d and -d2 are all given.`; with both flags and four paths the `--team` line shows, since `--team` is checked first. `--league NAME` is never a contradiction: convert-pdb reads the league in every run, for `play_path`; a league that does not resolve is the league error, as everywhere (cli-help.md rule 19).
10. **A shared plan is given once.** When a team's 1st- and 2nd-half plan is the same file (four teams today), two resolved slots that land on one file fill Slot 1 alone and Slot 2 is hidden, instead of two identical columns; `-o2 off1` on such a team resolves both slots to that one file and collapses the same way. If that one file is missing or unreadable, one `WARN` names it, not two. A typed plan beside a shared one (`-o try3.pln` on such a team) leaves the shared file in Slot 2 alone, and Slot 2 prints its own line (decision 12).
11. **A defaulted plan that is missing is a `WARN` and its column is hidden; a named one is a `FAIL`, as today.** The named/discovered rule (section 3): the coach did not name the file, and the stats workbook does not depend on it. check-ppp's league-locations `FAIL` is a checker's finding about files the game needs; convert-pdb is not checking them. A defaulted plan that cannot be read gets the same treatment, with the game plan library's reason. At the league locations the `WARN` carries check-ppp's hint as its last sentence, `Set ppp_path in <league.toml>, or pass --path.`, and a team whose `.lg2` folder is absent or holds none of its plans gets one `WARN` per folder instead of four (check-ppp plan, decision 6); in `ppp_path` or `--path` there is no hint, since the folder was the coach's choice.
12. **Each resolved slot's plan is named, as progress.** pytest names `testpaths` only when the run used it; the coach who typed a `.pln` path needs no echo, and the existing explicit-mode lines stay as they are. One line per slot athc resolved from the league file (a default or a name), path first (architecture.md: a line about a file starts with its path): `<path>: Denver 1st-half offense, Slot 1`; when both slots of a side resolve to one file, one line, `<path>: Las Vegas offense, both halves, Slot 1`; a shared file resolved for one slot alone gets the plain line for that slot (`<path>: Las Vegas 2nd-half offense, Slot 2`).
13. **A Slot column is hidden when its own plan is absent, not when the count is short.** Today a run with only a 2nd-half plan hides the column it fills (section 1); with decision 11 that run is reachable (a 1st-half plan missing in `ppp_path`). Slot positions stay fixed: Slot 1 is the 1st-half plan, Slot 2 the 2nd-half plan, whichever is present.
14. **Config problems are `FAIL`, in check-ppp's lines, each ending with this command's way out.** `team` set with no `path`, a `team` that matches no team or two, a bad or missing `.lg2` or `.lge`, two league files that disagree, `ppp_path` missing on disk: each is the line check-ppp-cli.md gives it, exit 2, so one problem reads one way in both commands (architecture.md: "one problem always reads one way") and the fix is the same one-time edit. The tails follow cli-help.md rule 21 and name a way out that works: with `team` set and `path` unset, every slot not given as a `.pln` still needs the league file and `--path` finds plans by `.lg2` name, which needs `path` too, so the "No path" tail is `or pass -o, -o2, -d and -d2 as .pln files.`; the "No team" line fires only when a name or `--path` forced the team, and its tail is `or pass --team or a .pln file.` when a name did (one `.pln` in its place leaves nothing asked for, decision 5) and `or pass --team.` when `--path` did (a `.pln` leaves `--path` in play, and four of them are the usage error). With nothing asked for, no team is silent (decision 5). A missing plan file is a weekly state of the coach's folders; a wrong setting is not.
15. **The side is checked.** A defense plan under `-o`/`-o2`, or an offense plan under `-d`/`-d2`, matches nothing and leaves a column that reads as "no play in the plan". A named one is `FAIL <path>: Not an offense game plan.`, exit 2, as check-ppp's side mismatch is the pair's failure; a defaulted one is the same text as a `WARN`, with the column hidden.
16. **`--skip-calcs` becomes `--percentages/--no-percentages`,** an on/off pair that overrides `calculate_percentages` in `athc.ini` both ways; neither given leaves the setting alone. This is git's negation ("Options with long option names can be negated by prefixing --no-") and its "options trump configuration" rule, and athc's own `--hot-corner/--no-hot-corner` pattern (cli-help.md's autocontinue text: "Overrides hot_corner in athc.ini (on by default)."); a one-way flag could never turn the columns on for one run. The workbook shows the columns when the run's value says so; the setting is the default, not a ceiling, so the `and` with it goes. cli-help.md planned `--skip-calculations`; the change is listed in section 11.
17. **New options: `--path FOLDER`, `--team NAME` and the `--percentages` pair; no `-a/--all-teams`, no `-r`, no quiet flag.** Two Slot columns per side hold two plans, so "every team" has no meaning here (coach only), and nothing is searched: `--path` names four files by name, so check-ppp's `-r` (its decision 9) does not apply; no athc command has a quiet flag (cli-help.md rule 24).
18. **`include_category_worksheets` and `exclude_sacks_from_pass_attempts` get no option.** They are per-workbook habits, not per-run choices. `include_category_worksheets` leaves the shipped `athc.ini` with this plan (TODO.md's item; `config/release/athc.ini` and `config/dev/athc.ini` today) and keeps its code default `False`, so `test_release_convert_pdb_defaults` keeps passing.
19. **Setup order: usage, the named files, the league and its config, the team, the league files, the plans, the output folder, then the pool and the PDB.** The named files (the PDB, the plans given as paths) are checked first, as today; then the league, `play_path` and `pdbtoexcel.toml` (the CLI loads them, decision 21); then `team` from `league.toml`, so a missing `team` shows before a missing `path` (cli-help.md rule 21); then the `.lg2` and `.lge` from `path` and the team match; then the `--path` folder, the plans' lines and `WARN`s; then the output folder, the pool, the PDB, `Creating`, the notices, `OK`. A `--team` typo shows before the pool's `WARN` lines, as check-ppp decision 12.
20. **The team resolver, the league-file loader and the file locator are shared code in `src/athc/cli/_team.py`** (cli-help.md rule 18; its contents are gameplan-cli.md section 9's), beside `_files.py` (`collect_files` is shared the same way), imported by check-ppp, gameplan, profile and convert-pdb; check-ppp's behavior is unchanged, and `team_option` is declared once in `src/athc/cli/__init__.py` beside `league_option` (cli-help.md rule 18).
21. **The CLI loads the config; the tool takes it.** Decision 19 needs `play_path` and `pdbtoexcel.toml` checked before the team, so `load_config` and `play_dir` move out of `main.convert_pdb()` into the command, which is how `check_ppp.py` and `generate_schedule.py` already do it (the command loads the tool's config, the tool takes what it needs); `convert_pdb()` takes the tool's `Config`. The `[league]` keys (`team`, `path`, `ppp_path`) come from `load_league_config(league)`, called by the command as `check_ppp.py`'s `load_lg2` does; the tool's `Config` stays as it is.
22. **Usage errors get athc's period once, where they are rendered** (cli-help.md rule 23). Click renders a `UsageError` in `UsageError.show()`; athc's `_OnePlace.main` catches the `ClickException` and calls `show()`, so that branch is the one place to give a message without a trailing period one, and every command prints `Got unexpected extra argument (x).` (architecture.md: usage errors end with a period); check-ppp-cli.md's own raise for a third path becomes unnecessary (section 11).

## 5. The command

```
Usage: athc convert-pdb [OPTIONS] PDB_FILE [OUTPUT_FILE]

  Convert a WinLogStats PDB to an Excel workbook.

  Slot 1 and Slot 2 show where each play sits in your team's 1st- and
  2nd-half game plans, per side; -o, -o2, -d and -d2 replace one each
  with a .pln file or one of the names off1, def1, off2 and def2.

Positional arguments:
  PDB_FILE     WinLogStats .pdb file.
  OUTPUT_FILE  .xlsx, or .xlsm to include sorting macros (default: PDB_FILE
               with .xlsm, beside it).

Options:
  -o, --pln-off GAME_PLAN     Offense Slot 1 (default: off1).
  -o2, --pln-off-2 GAME_PLAN  Offense Slot 2 (default: off2).
  -d, --pln-def GAME_PLAN     Defense Slot 1 (default: def1).
  -d2, --pln-def-2 GAME_PLAN  Defense Slot 2 (default: def2).
  --path FOLDER               Folder holding your team's game plans, by their
                              league-file names (default: ppp_path, else where
                              the game reads them).
  --team NAME                 Team whose game plans fill the Slot columns
                              (default: team in league.toml).
  --percentages / --no-percentages
                              Overrides calculate_percentages in athc.ini (on
                              by default).
  --league NAME               League to use (default: the one set with athc
                              config set league).
  -h, --help                  Show this message and exit.

  Examples:

    athc convert-pdb 49W6.pdb
    athc convert-pdb 49W6.pdb reports\week6.xlsx -o try3.pln
```

Examples for the docs:

```
athc convert-pdb 49W6.pdb
athc convert-pdb 49W6.pdb reports\week6.xlsx
athc convert-pdb 49W6.pdb --team Broncos
athc convert-pdb 49W6.pdb -o try3.pln -o2 off1
athc convert-pdb 49W5.pdb --path plans\wk5
athc convert-pdb 2045-2047.pdb --no-percentages --league PCFL
for %f in (*.pdb) do athc convert-pdb "%f"
```

### Modes

Per slot: a slot given as a `.pln` path is that file; a slot given as a name, or not given, is resolved from the league file.

| Slot given as | `--path` | Team | The plan comes from | What is missing |
|---|---|---|---|---|
| a `.pln` path | any | not needed for it | that file | `FAIL`, exit 2, as today |
| a name, or nothing | `FOLDER` | `team` or `--team` | that folder, by the plan's `.lg2` name without case | `WARN`, column hidden |
| a name, or nothing | none; `ppp_path` set and the team is `team`'s | your team | `ppp_path`, by the `.lg2` name without case | `WARN`, column hidden |
| a name, or nothing | none | `team` or `--team` | the league locations: `path` joined with the plan's `.lg2` folder | `WARN` with the `ppp_path` hint, column hidden |
| nothing | none | no `team`, no `--team` | nothing | the Slot columns hidden; no line |
| a name | any | no `team`, no `--team` | nothing | `FAIL`: the "No team" line, tail `or pass --team or a .pln file.` |
| nothing or a name | `FOLDER` | no `team`, no `--team` | nothing | `FAIL`: the "No team" line, tail `or pass --team.` |

- **Output:** `OUTPUT_FILE` as given, else `<PDB folder>\<PDB name>.xlsm`; its missing folders are created in full and an existing file is replaced, as today.
- **Team mode:** `team` is read from `league.toml`, then the `.lg2` and `.lge` from `path`; the team's four plan entries are taken in `.lg2` order; two resolved slots on one file are read once and fill Slot 1 alone. Each plan is read before the pool, so its line or `WARN` comes first. `--path` must be an existing folder; the plans are looked up in it alone (no subfolders).
- **Order of output:** config and team `FAIL`s (nothing else prints); the resolved slots' lines and `WARN`s in `.lg2` order; `Creating '<output>'`; the pool, rules, PDB and workbook `WARN`s as today; the `OK` line.
- **Argument errors:** a missing `PDB_FILE`, a bad extension, a second `.pdb` and a wildcard are Click usage errors, exit 2, with the uppercase names; a third positional is `Error: Got unexpected extra argument (<x>).`, Click's text with athc's period added once where usage errors are rendered (decision 22); `--team` or `--path` with four `.pln` paths and `--skip-calcs` (gone) are usage errors; a PDB or a named plan that does not exist keeps today's `FAIL` with Windows' phrase; a `--path` folder that does not exist is `FAIL <folder>: The system cannot find the path specified.`, a file `The directory name is invalid.`; an `OUTPUT_FILE` whose folder is a file keeps today's `FAIL <folder>: Cannot create a file when that file already exists.`

## Shared vocabulary

- **The four names: `off1`, `def1`, `off2`, `def2`** (cli-help.md rule 17): your team's 1st-half offense, 1st-half defense, 2nd-half offense and 2nd-half defense game plan, the `.lg2`'s entries in that order, matched without case; an existing path wins; two names may be one file. In convert-pdb they are the defaults of `-o`, `-d`, `-o2` and `-d2` and accepted values of each.
- **A folder that takes one of the four names** (cli-help.md rule 21): `FAIL off1: Access is denied. Run from another folder to use your team's game plan.`
- **Derived output:** an optional `OUTPUT_FILE` whose default is the input's name with the product's extension, beside the input (`list-normals`: `<name>.normals.txt`; convert-pdb: `<name>.xlsm`); help says "(default: <INPUT> with .<ext>, beside it)". convert-pdb's is a workbook, so `-` is refused (cli-help.md rule 3's exception).
- **`GAME_PLAN`** (option value): "a .pln file or one of the four names"; convert-pdb's `-o`, `-o2`, `-d`, `-d2`.
- **`--path FOLDER`** (cli-help.md rule 20): `--path` means "where the game plans are" on every command that has it; what is taken from there follows the command. gameplan's batch commands act on every game plan they find (a `.pln`, a folder, a wildcard, or one of the four names), because they edit or search whatever is there; convert-pdb takes a folder only and picks the team's four plans by their `.lg2` names, because the workbook has exactly four slots. Help here: "Folder holding your team's game plans, by their league-file names (default: ppp_path, else where the game reads them)."
- **`--team NAME`** (cli-help.md rule 18): `team_option` in `src/athc/cli/__init__.py`; help "Team whose game plans fill the Slot columns (default: team in league.toml)." here; with four `.pln` paths, `Error: Cannot use --team with a path.` (rule 18); `--league NAME` is never a contradiction, and a named league must exist (cli-help.md rule 19).
- **`--path` with nothing to find:** `Error: Cannot use --path when -o, -o2, -d and -d2 are all given.`; with `--team` too, the `--team` line shows.
- **`--<on>/--no-<on>`:** an on/off pair over an `athc.ini` boolean, `default=None`, help "Overrides <key> in athc.ini (on by default)." (autocontinue's `--hot-corner`, convert-pdb's `--percentages`).
- **One input per run:** the hint sentence `To convert several, run for %f in (*.pdb) do athc convert-pdb "%f".`
- **A third positional:** `Error: Got unexpected extra argument (x).`, Click's text with the period added once in `src/athc/cli/__init__.py` (cli-help.md rule 23).
- **Half names:** "1st-half offense", "2nd-half defense", "both halves", from the `.lg2` spec and check-ppp's plan.
- **Slot words:** "Slot 1" is the 1st-half plan, "Slot 2" the 2nd-half plan, per side.
- **A resolved file in use:** a progress line `<path>: <Team> <half> <side>, Slot <n>`; both slots of a side on one file: `<path>: <Team> <side>, both halves, Slot 1`.
- **A resolved file unusable:** `WARN <path>: <reason> <Side> Slot <n> is hidden.`, at the league locations followed by `Set ppp_path in <league.toml>, or pass --path.`; none of a team's files in a folder: `WARN <folder>: No <Team> game plans.` (check-ppp: `No <Team> files.`).
- **"No team" / "No path" tails** (cli-help.md rule 21): `or pass --team or a .pln file.` after a name, `or pass --team.` after `--path`; `or pass -o, -o2, -d and -d2 as .pln files.` for "No path".
- **Side mismatch of a game plan:** `<path>: Not an offense game plan.` / `Not a defense game plan.`
- **Code and fixtures:** `src/athc/cli/_team.py` with `TEAM_FILE_NAMES`, the three key constants, `load_league_files`, `resolve_team`, `team_files(team, kind)` (the four `(name, file)` pairs, repeats kept), `locate(file, ppp_path, league_path) -> Located(path, exists, source)`, all as gameplan-cli.md section 9 decides; `tests/integration/conftest.py` fixtures `build_league`, `lg2_league`, `pnfl_league` and the `team()` builder (gameplan-cli.md section 10).

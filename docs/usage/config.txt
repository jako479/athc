athc config
===========


config  --  show or change athc settings (athc.toml, league.toml)
   --------------------------------------------------------------

   Show, open, read or change the athc settings files, so you don't have to
   hunt for the hidden %LOCALAPPDATA%\athc folder: athc.toml holds the
   league in use ([athc] league) and each tool's app-wide settings; a
   league's leagues\<NAME>\league.toml holds its path, play_path, team and
   ppp_path.

   `path`, `edit` and `reveal` take FILE, athc.toml (the default) or
   league.toml, in any case, and --league NAME (which makes league.toml the
   default). `path` prints the file's full path (the file need not exist);
   `edit` opens it in its default app (a missing athc.toml is created empty
   first; a missing league.toml is a FAIL, and nothing is created);
   `reveal` shows the file in File Explorer (selected), or opens its folder
   if the file doesn't exist yet.

   `get KEY` prints a setting: league from athc.toml, checked against the
   league folders; path, play_path, team and ppp_path from the league's
   league.toml, a relative path resolved against the league folder
   (--league NAME picks another league). `set KEY VALUE` writes one: league
   to athc.toml (the value must be a folder under leagues\), the other four
   to the league's league.toml, as supplied. It keeps your comments in both
   files and prints an OK line naming the file it wrote, e.g.
   OK   <league.toml>: team = Denver. --league is not valid with set league.

   KEY is league, path, play_path, team or ppp_path, in any case. --league
   NAME on every verb picks the league; without it, the league in use. A
   named league must have a folder under leagues\.

   Show help:
      athc config --help

   Example terminal calls:
      athc config path [FILE]          print the path of athc.toml or league.toml
      athc config edit [FILE]          open it in its default app
      athc config reveal [FILE]        show it in File Explorer
      athc config get KEY              print a setting
      athc config set KEY VALUE        change a setting, keeping the file's comments

      athc config path
      athc config edit league.toml
      athc config reveal
      athc config get play_path
      athc config set league PNFL
      athc config set play_path C:\SIERRA\FBPRO98\PNFL
      athc config set team Denver

   Lines and exit codes:

      path, get done:
         the path or value (stdout), 0
      edit, reveal done:
         nothing, 0
      set done:
         OK   <file>: <key> = <value>, 0
      get ppp_path, not set:
         WARN <league.toml>: Game plan and profile folder is not set. The
         folders the league file names are used., 0
      get path, play_path or team, not set:
         FAIL <league.toml>: ... is not set. Run 'athc config set <key>
         ...'., 2
      no league set, or no folder for it:
         FAIL League is not set. ... or FAIL League 'X' not found. ..., 2
      league.toml missing or without [league] (set, edit):
         FAIL <league.toml>: The system cannot find the file specified., 2
      a malformed athc.toml or league.toml:
         FAIL <file>: Not valid TOML: ..., 2
      edit, a file Windows cannot open:
         FAIL <file>: <Windows' text>, 2
      unknown KEY or FILE, a set league name with no folder, any other
      usage error:
         Click's Error: line, 2

      The shared scheme: EXIT CODES in README.txt. The files are found
      through the settings folder (see README.txt); there is no --config
      flag.

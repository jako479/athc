athc profile
============

Check, compare and copy FbPro98 coaching profiles (.prf).


Shared by every profile command
   ----------------------------

   Profile keys. off1, def1, off2 and def2 are your team's 1st-half offense,
   1st-half defense, 2nd-half offense and 2nd-half defense profiles. Every
   profile operand takes them, in any case: check's PATH, diff's PROFILE1
   and PROFILE2, copy's SOURCE and TARGET.

   - Your team is team in league.toml, or --team NAME (name, nickname or
     both).
   - A key's file is its .lg2 name in ppp_path (the team team only), else
     where the league file puts it (path joined with its .lg2 folder).
   - Something of that name in the current folder, or a word with an
     extension or a folder separator, is a path: off1.prf, .\off1 and a
     folder named off1 are never keys.
   - --team needs a key among the operands.
   - A key's file that is not there is a FAIL; for the team team at its
     league location the line adds Run 'athc config set ppp_path FOLDER' or
     pass a .prf file.
   - The setup lines (team or path not set, the league files, no team
     matching) are check-ppp's, ending or pass a .prf file.

   --league NAME picks the league; a named league must exist. Its files are
   read only when the run needs them: check always (its rules), diff and
   copy only for a key.

   Rules. Rules are not built in -- they are the league folder's
   profile.toml (leagues\<NAME>\ under the settings folder, picked by
   --league / [athc] league). To layer several files, list them in
   league.toml:

      [league]
      profile_rules = ['profile.toml', 'house-rules.toml']

   Later files layer over earlier. With no rules configured, check reports
   an error and exits 2. The shipped rule set is leagues\PNFL\profile.toml,
   and its comments explain every key.

   Lines and exit codes. Results, OK and SKIP lines go to stdout; WARN and
   FAIL lines, progress and usage errors to stderr; every status line is
   also in the run log. The same codes everywhere: 0 done (warnings
   included), 1 findings, 2 error (usage, config, a bad or missing file, a
   file that failed inside a batch, a bug). A batch processes every file and
   exits with the worst outcome. A named file that does not exist is
   FAIL <file>: The system cannot find the file specified. Each command's
   lines are under its section below; the shared scheme is EXIT CODES in
   README.txt.


profile check  --  check profiles against the league's rules
   ---------------------------------------------------------

   Rules come from the league's profile.toml. With no rules configured,
   check reports an error and stops. With no path, every .prf in the current
   folder is checked (the whole tree with -r). Each PATH is a .prf file, a
   folder (top level, or the whole tree with -r), a wildcard or a profile
   key; each profile prints OK or its violations, in PATH order. To check a
   profile together with its game plan, run athc check-ppp.

   Show help:
      athc profile check -h

   Example terminal calls:
      athc profile check
      athc profile check off2
      athc profile check drafts\*OFF*.prf
      athc profile check profiles -r --league PCFL

   Lines: per file OK   <file>: <side>, FG range ... or the headline
   <file>: <n> violation(s) (...) with its indented detail lines; a blank
   line; <n> file(s) checked, <n> with violations, <n> failed. Exit 1 on
   violations.


profile copy  --  copy settings from one profile to others
   -------------------------------------------------------

   Copies the settings you pick (--stop-clock, --substitutions,
   --field-goal-range, --fourth-down, --goal-line, --pat-logic; at least
   one) from SOURCE into each TARGET, each file once, in TARGET order.
   SOURCE is a .prf file or a profile key; each TARGET is a .prf file, a
   folder (-r includes subfolders), a wildcard or a profile key. Targets of
   the other side, and the source itself, are skipped with a SKIP line; the
   source as the only TARGET file is an error (The file cannot be copied
   onto itself., Windows' copy words). A missing SOURCE, or that error,
   stops the run before any target is touched. No backup is made. Copy does
   not check the rules -- run athc profile check afterward.

   Show help:
      athc profile copy -h

   Example terminal calls:
      athc profile copy off1 off2 --stop-clock --substitutions
      athc profile copy new.prf off1 off2 --substitutions
      athc profile copy SRC.prf profiles --stop-clock -r

   Lines: OK   <file>: updated (stop-clock, substitutions, ...),
   SKIP <file>: <other side> profile and SKIP <file>: the source profile,
   FAIL <file>: <why>; the source as the only target file is FAIL <file>:
   The file cannot be copied onto itself., 2; a tally <n> file(s)
   processed, <n> updated, <n> skipped, <n> failed; no copy option is a
   usage error. Exit 0 (done, skips included) or 2 (an error, or a target
   failed); never 1.


profile diff  --  show differences between two profiles
   ----------------------------------------------------

   Shows what changed from PROFILE1 to PROFILE2: situations, PAT
   situations, substitutions, field-goal range, and audibles; only changed
   records are shown. Both profiles must be the same side; each is a .prf
   file or a profile key, and the report names the file a key stands for.
   Prints to the screen, or with -o FILE writes a report (.txt report, .csv
   one row per changed record for Excel), creating its missing folders. No
   rules needed; use it to preview a copy.

   Show help:
      athc profile diff -h

   Example terminal calls:
      athc profile diff off1 off2
      athc profile diff off1 try.prf -o changes.csv

   Lines: the report; with -o, OK   <file>: written; different sides are
   FAIL Cannot compare <a> (offense) with <b> (defense)., 2; a bad -o
   extension is a usage error. Exit 0 (identical), 1 (any difference) or 2
   (an error or a side mismatch).

athc - SCHEDULER (Commissioner only)
====================================

Builds a league's season schedule. This tool is intentionally left out of the
general COMMANDS.txt -- it is for the league Commissioner.

The scheduler uses the OR-Tools solver, which the installer already includes.
(If a broken install is missing it, athc says so; re-run install.bat.)


generate-schedule  --  build the season schedule
   ----------------------------------------------

   Reads the league's standings file, solves the schedule, and writes a .txt
   and .html schedule plus a sortable HTML report (per-team strength of
   schedule; click a column header to sort) to the current folder. Files are
   named schedule_<season>_<timestamp>; the report adds a _report.html suffix.

   Show help:
      athc generate-schedule --help

   Example terminal calls:
      athc generate-schedule --league PNFL --season 2048
      athc generate-schedule --league PCFL --season 2029 --seed 7

   Options:
      --league NAME       league to schedule (a [league.NAME] section in
                          athc.ini); or set ATHC_LEAGUE, or [athc]
                          default_league
      --season YEAR       (required) season to schedule, e.g. 2048; reads
                          <league>.<season>.ini from the config dir
                          (run 'athc config path')
      --seed INT          random seed for reproducible output
      --time-limit SECS   override the solver time limit (CP-SAT
                          deterministic time, not wall-clock seconds)

   Exit 0 = written, 1 = error (league, config, no feasible schedule),
   2 = bad arguments.


CONFIG FILES (in %LOCALAPPDATA%\athc\)
   ------------------------------------

   <league>.<season>.ini (e.g. PNFL.2048.ini, PCFL.2029.ini) -- the standings.
   You supply this; --league and --season pick which file to read. Sections:

      [OverallStandings]   Last season's final standings: all 18 teams, one
                           per line, 1st (best) through 18th. Per-conference
                           ranks derive from it. Required.
      [DivisionStandings]  A league with divisions: each division's teams in
                           last season's finish order, best first. The key
                           names the conference and the division
                           (AFC_EAST, NFC_WEST, ...); the line count is the
                           division's size. Two conferences of nine teams.
      [ConferenceStandings] A league without divisions: each conference's
                           teams in finish order, best first. Two conferences
                           of nine teams.

      A file has exactly one of [DivisionStandings] and [ConferenceStandings].

   rules\<league>.scheduler.toml -- optional tuning (difficulty tilt, solver
   time limits, weeks, rule amounts and toggles, rivalries). Every key
   defaults if absent; edit only to change a default. See the comments in
   the shipped PNFL and PCFL files.

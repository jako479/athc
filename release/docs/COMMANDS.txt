athc - COMMANDS
===============

What each athc tool does, with examples. For installation and setup,
see README.txt in this same folder.

Run tools from any terminal (Command Prompt or PowerShell):

   athc --help                        list top-level commands
   athc <group> --help                list subcommands in a group
   athc <group> <subcommand> --help   show help for one subcommand

Settings live in athc.ini (the file documents every option inline). Each league
is a folder under leagues\ next to it: league.ini (play_path), rules\
(gameplan.toml, profile.toml, playpool.toml, scheduler.toml) and standings\
(<season>.league.ini). League-aware tools use the league named by [athc] league
unless the command is given --league NAME.


1) gameplan check  --  validate a .pln game plan against league rules
   ------------------------------------------------------------------

   Rules come from the league's rules\gameplan.toml. The play pool comes from
   the league's play_path (plus rules\playpool.toml). Each play's
   side and category come from the play file, so any folder layout works; the
   PNFL layout (Offense/Defense/Special with category subfolders) is optional and
   only adds play attributes and misfiled-play warnings. With no gameplan rules
   configured, check reports an error and stops.

   Show help:
      athc gameplan check --help

   Example terminal calls:
      athc gameplan check offense.pln
      athc gameplan check plans\ -r
      athc gameplan check offense.pln --league PCFL


2) gameplan list-normals  --  list the 64 normal plays from a .pln
   ----------------------------------------------------------------

   Default writes <name>.normals.txt next to the .pln, replacing any existing
   copy; pass an output file to write elsewhere, or - to print to the screen.
   A file's first line is a `::` comment with the absolute path of the source
   .pln. --sort name lists alphabetically (default keeps slot order).

   Show help:
      athc gameplan list-normals -h

   Example terminal calls:
      athc gameplan list-normals offense.pln
      athc gameplan list-normals offense.pln plays.txt --sort name
      athc gameplan list-normals offense.pln -


3) gameplan list-specials  --  list the custom special-teams plays
   ----------------------------------------------------------------

   Lists them in source-file order. Default writes <name>.specials.txt next to
   the .pln, replacing any existing copy; pass an output file to write
   elsewhere, or - to print to the screen. A file's first line is a `::`
   comment with the absolute source path.

   Show help:
      athc gameplan list-specials -h

   Example terminal calls:
      athc gameplan list-specials offense.pln
      athc gameplan list-specials offense.pln spec.txt
      athc gameplan list-specials offense.pln -


4) gameplan find-play  --  find plays by name across .pln files
   ------------------------------------------------------------

   Searches a single .pln, every .pln in a directory, or a tree (-r).
   Case-insensitive; only the normal and custom-special slots are searched
   (stock/clock slots skipped). Hits show the slot(s), e.g.
   'OR45RL01' found in slots 1-3, 16-2; special-teams hits add the category,
   e.g. 'BCFGPAT' found in special slot 1 (Field Goal/PAT). No pool setup
   needed -- the category is read from the .pln. A file without the play
   prints `not found`; a directory/tree ends with a per-play summary.

   Show help:
      athc gameplan find-play -h

   Example terminal calls:
      athc gameplan find-play OR45RL01 offense.pln
      athc gameplan find-play OR45RL01 BCFGPAT plans\ -r


5) gameplan set-normals  --  set the 64 normal plays in a .pln
   -----------------------------------------------------------

   Replaces the normal slots of one .pln from a play list file; - reads the
   list from the screen instead. No backup is made. Input lines starting
   with `::` are comments; ` ::` after a name (with a space) is inline. The
   league's play pool resolves names; run `check` to validate.

   Show help:
      athc gameplan set-normals -h

   Example terminal calls:
      athc gameplan set-normals offense.pln plays.txt
      athc gameplan set-normals offense.pln plays.txt -q


6) gameplan set-specials  --  set the custom special-teams plays
   -------------------------------------------------------------

   Updates one .pln, every .pln in a directory, or a tree (-r), from a play
   list file; - reads the list from the screen instead. Wrong-side files are
   skipped silently (offense .pln are even-sized, defense odd). Merge
   semantics: unlisted special categories are kept. No backup is made.
   Comment syntax: same as set-normals.

   Show help:
      athc gameplan set-specials -h

   Example terminal calls:
      athc gameplan set-specials offense.pln spec.txt
      athc gameplan set-specials plans\ spec.txt -r


7) gameplan replace-play  --  swap one play for another across .pln files
   ----------------------------------------------------------------------

   Replaces every instance of one play with another in a single .pln, every
   .pln in a directory, or a tree (-r). Searches the normal and custom-special
   slots, case-insensitive (same as find-play); only matching slots change, the
   rest are left alone. The replacement play must exist in the league's play
   pool (its play_path); the play being replaced need not (it may already be
   gone). No backup is made. Rules are not checked -- run `gameplan check`
   afterward to validate.

   Each replaced play prints a line; a play in several slots lists them all
   in brackets at the end, e.g.:
      offense.pln: 'OR45RL01' (RL) replaced with 'OR43RM02' (RM) [1-3][4-2]

   Show help:
      athc gameplan replace-play -h

   Example terminal calls:
      athc gameplan replace-play OLDRUN NEWRUN offense.pln
      athc gameplan replace-play OLDRUN NEWRUN plans\ -r


8) profile check  --  validate a .prf coaching profile against league rules
   ------------------------------------------------------------------------

   Rules come from the league's rules\profile.toml. With no rules configured,
   check reports an error and stops.

   --gameplan pln_file also checks the profile's play categories against a .pln
   gameplan: every category the profile uses (normal and special teams) must
   have a custom play in the gameplan. It also reports gameplan categories the
   profile never uses. The league's rules\profile.toml turns each direction on.
   Profile and gameplan must be the same side (offense or defense).

   Show help:
      athc profile check -h

   Example terminal calls:
      athc profile check OFF1.prf
      athc profile check profiles\ -r --league PCFL
      athc profile check OFF1.prf --gameplan OFF.pln


9) profile copy  --  copy fields from a source .prf into targets
   --------------------------------------------------------------

   Updates a single .prf, every .prf in a directory, or a tree (-r).
   Wrong-side files are skipped silently. No backup is made. Copy does not
   validate -- use `profile check` for that.

   Show help:
      athc profile copy -h

   Example terminal calls:
      athc profile copy SRC.prf DST.prf --stop-clock --goal-line
      athc profile copy SRC.prf profiles\ --stop-clock -r


10) profile diff  --  show differences between two coaching profiles
    ----------------------------------------------------------------

   Compares situations, PAT situations, substitutions, field-goal range,
   and audibles; only changed records are shown. Both files must be the
   same side. Prints to the screen, or with --output file writes a report
   (.txt report, .csv one row per changed record for Excel).

   Show help:
      athc profile diff -h

   Example terminal calls:
      athc profile diff OFF1.prf OFF2.prf
      athc profile diff OFF1.prf OFF2.prf --output changes.csv


11) check-ppp  --  check a profile and/or a game plan, and how they fit
    -------------------------------------------------------------------

   Checks one .prf coaching profile, one .pln game plan, or both, in either
   order (the extension tells them apart). Each file gets the same check as
   profile check and gameplan check, with the rules from the current league;
   --league picks another league. With both files, they must be the same
   side, and the league's rules\profile.toml decides whether profile
   categories with no custom play in the game plan, and game plan categories
   the profile never uses, fail the check. Unused game plan categories that
   don't fail are listed as info only. Every error is reported, not just the
   first.

   Show help:
      athc check-ppp -h

   Example terminal calls:
      athc check-ppp OFF1.prf OFF.pln
      athc check-ppp OFF1.prf
      athc check-ppp OFF.pln


12) check-playpool  --  check the play pool for misfiled and duplicate plays
    ------------------------------------------------------------------------

   Checks every play under the league's play_path, or under a folder you
   give instead (then no league is needed); --league picks another league.
   Reports plays in a folder that doesn't match the play file, duplicate play
   names, and invalid play files -- the same warnings other commands show
   when they load the play pool. Ends with a count of plays
   checked and issues found.

   Show help:
      athc check-playpool -h

   Example terminal calls:
      athc check-playpool
      athc check-playpool E:\SIERRA\FbPro98\PNFL
      athc check-playpool --league PCFL


13) convert-pdb  --  WinLogStats stats (.pdb) into Excel
    ----------------------------------------------------

   Builds an Excel workbook (.xlsx, or .xlsm for embedded sorting macros)
   from a WinLogStats .pdb. Cross-reference up to two offensive (-o/-o2)
   and two defensive (-d/-d2) game plans to tag plays. The workbook always
   includes a Total Stats team. The other workbook options (percentage
   columns, per-category worksheets, sacks excluded from pass attempts) live
   in athc.ini under [convert-pdb]; --skip-calcs drops the percentage columns
   for one run. Play tags (QB draw, rollout, timed pass) come from the
   league's rules\playpool.toml.

   Show help:
      athc convert-pdb --help

   Example terminal calls:
      athc convert-pdb stats.pdb output.xlsm
      athc convert-pdb stats.pdb output.xlsm -d defense.pln -o offense.pln


14) autocontinue  --  auto-click the FbPro '98 'Continue' button between plays
    --------------------------------------------------------------------------

   Watches for the 'Continue' button and clicks it between plays. Settings
   live in athc.ini ([autocontinue] mouse_move_duration, delay_before_continue,
   hot_corner) and are re-read whenever the file changes. It only clicks while
   the game is the active window, so switching to another app is safe. Run the
   game on your primary monitor (autocontinue only watches that display; a
   single-display VM works too). Stop it with CTRL-C, or by moving the mouse to
   the top-left screen corner (the "hot corner", on by default).

   Set hot_corner = false (or pass --no-hot-corner) to turn the corner off and
   use CTRL-C only; --hot-corner forces it on for one run.

   Show help:
      athc autocontinue --help

   Example terminal calls:
      athc autocontinue
      athc autocontinue --no-hot-corner


15) config  --  locate, edit, reveal, or set your athc settings
    ----------------------------------------------------------

   Helpers for the settings file (athc.ini) and its folder. `path` prints
   the file's full path; `edit` opens it in your default app for .ini files,
   created if missing; `reveal` shows athc.ini in File Explorer (selected),
   or its folder if it doesn't exist yet.

   `set KEY VALUE` writes one key under [athc], keeping your comments. Today
   the only key is league: the league used when --league is not given. The
   value must be a folder under leagues\.

   Show help:
      athc config --help

   Example terminal calls:
      athc config path
      athc config edit
      athc config reveal
      athc config set league PNFL


EXIT CODES
==========

   0 always means success. The meaning of 1 and 2 depends on the command.

   Checks and comparisons -- gameplan check, profile check, check-ppp,
   check-playpool, profile diff, find-play, and the bulk editors
   set-specials, replace-play, and profile copy:
      0   clean -- nothing to report
      1   ran, but found problems (violations, play pool issues,
          differences, no play found, nothing replaced, or some files
          failed)
      2   could not run (bad arguments, config or I/O error, no rules, a
          profile and game plan of different sides, or the replacement play
          is not in the pool)

   All other commands either succeed or fail:
      0   success
      1   an error (could not read/write a file, bad config, missing
          dependency)
      2   bad command-line arguments

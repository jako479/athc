athc - SCHEDULER (Commissioner only)
====================================

Builds the season schedule. This tool is intentionally left out of the general
COMMANDS.txt -- it is for the league Commissioner.

The scheduler needs the OR-Tools solver. If it isn't installed, athc will say
so; install it with:

   pip install athc[schedule]


generate-schedule  --  build the season schedule
   ----------------------------------------------

   Reads the league and the non-conference history, solves the schedule, and
   writes it plus a companion text report. The output format comes from
   --format, else the --output extension (.htm / .html / .txt). The report is
   written next to the output (season.txt -> season-report.txt).

   Show help:
      athc generate-schedule --help

   Example terminal calls:
      athc generate-schedule --output season.html --season 2026
      athc generate-schedule --output season.txt --season 2026 --seed 7

   Options:
      --output FILE       (required) where to write the schedule
      --season YEAR       (required) season being scheduled, e.g. 2026
      --format X          htm | html | txt (else inferred from --output)
      --league FILE       use this league.ini instead of the default
      --history FILE      use this nonconf_history.json instead of the default
      --report FILE       report path (default <output-stem>-report.txt)
      --seed INT          random seed for reproducible output
      --time-limit SECS   override the solver time limit
      --scheduler NAME    two-phase-rank (default) or fixed-matchup

   Exit 0 = written, 2 = error.


CONFIG FILES (in %LOCALAPPDATA%\athc\)
   ------------------------------------

   league.ini -- divisions and last season's standings. You supply this. Two
   sections:

      [Divisions]   the four divisions and their teams (AFC_EAST 4 teams,
                    AFC_WEST 5, NFC_EAST 4, NFC_WEST 5).
      [Standings]   Order = last season's final standings: all 18 teams, one
                    per line, 1st (best) through 18th. The scheduler ranks
                    teams from this; per-conference ranks are derived from it.

   (The older [ConferenceRanking] format -- separate AFC and NFC 1-9 lists --
   is still accepted, but only works with --scheduler fixed-matchup.)

   nonconf_history.json -- the last year each AFC team played each NFC team,
   used to space out repeat non-conference matchups.

   rules\PNFL.scheduler.toml -- optional tuning (difficulty curve, solver time
   limits, phase-2 rule amounts). Every key defaults if absent; edit only to
   change a default. See the comments in that file.
